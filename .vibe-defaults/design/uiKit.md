# Карта UI проекта

> Читается ПЕРВОЙ, когда правится интерфейс. Отвечает на один вопрос: **это уже есть?**
> Остальные файлы контура отвечают, каким оно должно быть; этот — есть ли оно вообще.
>
> Заполните под свой проект и удалите примеры. Пустая карта не вредит — она просто молчит.

## Зачем этот файл

Модель, которой сказано «добавь кнопку», добавляет **новую** кнопку: имён она не знает, а пустое
место достраивает сама. Отсюда интерфейсы, где пять разных кнопок и три вида карточек — не потому
что модель плохо рисует, а потому что ей не сказали, что рисовать нечего.

Правило, ради которого файл существует: **сначала найди готовое, потом создавай.**

## 1. Где что лежит

Таблица разбирается автоматически: три колонки, ровно в этом порядке.

| Слой | Файл | Что внутри |
|---|---|---|
| Токены | `src/styles/tokens.css` | переменные `--color-*`, `--space-*`, `--radius-*` |
| Компоненты (CSS) | `src/styles/components.css` | классы `.btn`, `.card`, `.field`, `.badge` |
| React-примитивы | `src/components/ui.tsx` | `Button`, `Card`, `Field`, `EmptyState`, `Toast` |
| Иконки | `src/components/icons.tsx` | единый набор, размер задаётся пропом |
| Живой каталог | `src/pages/ui-kit.tsx` | страница со всеми компонентами разом |

## 2. Имена, на которые ссылаться

Пишите имя дословно, в обратных кавычках — оно попадёт агенту списком: `Button`, `Card`,
`EmptyState`, `.btn`, `.btn--ghost`, `--color-accent`.

В задаче ссылайтесь по имени: «добавь `Card` с `EmptyState` внутри», а не «сделай карточку
покрасивее». Второе для модели неоперационально — она достроит своё.

## 3. Правило источника правды

- Значение, которое повторяется, → выносится в **токен**.
- Класс или разметка, которые повторяются инлайном, → выносятся в **компонент**.
- Дубликат не создаётся никогда: если готовое не подходит, **расширяется существующее**, а не
  заводится второе рядом.

## 4. Do / Don't

Короткие запреты — то, что модель повторяет чаще всего.

- **Don't:** двойной отступ между соседними блоками одного цвета. Отступ задаёт один из них.
- **Don't:** новая тень, радиус или цвет «под этот случай» — берите из токенов.
- **Do:** пополнять эту карту, **когда модель ошиблась**. Файл пишется не впрок, а по факту
  промаха: не нашлось имени — значит его здесь не было.
