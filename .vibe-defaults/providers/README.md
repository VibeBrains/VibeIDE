# Примеры провайдеров — `.vibe/providers/`

Библиотека готовых конфигов LLM-провайдеров (по файлу на провайдера). Это **примеры для копирования**, не автозагружаемые конфиги: VibeIDE читает `.vibe/providers.json` проекта и глобальный `~/.vibe/providers.json` (провайдер во всех проектах; при совпадении id файл проекта перекрывает глобальный).

**Как применить:**
- скопируйте содержимое нужного файла в `.vibe/providers.json` проекта или в `~/.vibe/providers.json` (если файла нет — создайте), **или**
- перенесите объект провайдера из `providers[]` примера в свой существующий массив `providers`.

Каждый файл — валидный самодостаточный `providers.json` (JSONC: можно `//`-комментарии).

**Ключи API в файле не хранятся** — только `apiKeyEnv` (переменная окружения / `.vibe/.env`) или `apiKeyRef` (защищённые настройки). После структурных правок (id/baseURL/модели) перезапустите VibeIDE.

Полная спецификация формата — [`docs/manuals/providersSpec.md`](https://github.com/VibeBrains/VibeIDE/blob/main/docs/manuals/providersSpec.md). Общий пример со всеми рецептами — `.vibe/providers.example.jsonc`.
