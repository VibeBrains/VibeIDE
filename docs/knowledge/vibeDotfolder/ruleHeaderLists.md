# Списки в шапке правил: `globs` и `triggers`

← [Knowledge Index](../README.md)

Как `ruleFrontmatter.ts` читает значения-списки в шапке `.mdc` и почему запятая не всегда разделитель.

---

## [правило] Три формы списка и правило деления

**Контекст:** разбор шапки резал значение по каждой запятой и не знал скобочной формы.
Из-за этого `ui-kit.mdc` из общего набора (`globs: **/*.{css,scss,sass,less,tsx,jsx,vue,svelte,html}`) не срабатывал ни на одном файле:
glob распадался на девять кусков, первый и последний с лишней фигурной скобкой.
И `triggers: [a, b]` читался как фразы `[a` и `b]`: правило не включалось на первое и последнее слово.
Сосед (VibeIDEA) нашёл оба дефекта, сверяя разборы, и записал их общими для набора.

**Суть:** значение списка пишется в любой из трёх форм, пункты те же.

```
globs: **/*.{css,scss}, docs/**/*.md          через запятую
globs: ["**/*.{css,scss}", "docs/**/*.md"]    список в скобках
globs:                                        список с дефисами
  - **/*.{css,scss}
  - docs/**/*.md
```

Правило деления одно, на все три формы:

- **Запятая делит пункты только вне кавычек, `{}` и `[]`.** `{css,scss}` и `[a,b]` внутри пункта остаются целыми
- **Перевод строки делит всегда** и сбрасывает глубину скобок. Строка списка с дефисами — один пункт, лишняя скобка в ней не съедает строки ниже
- **Кавычка открывает пункт только в его начале.** `"fix, then deploy"` — одна фраза; апостроф в слове (`don't stop`) не кавычка
- **Скобки вокруг всего значения — синтаксис списка, только если открывающая закрывается в самом конце** и внутри нет лишней `]`.
  `[a, b]` — список; `[ab]*.ts` и `src/[a-c].ts` — glob с классом символов и остаются как есть.
  Единственный glob, целиком заключённый в скобки (`[ab]`), читается как список из одного пункта `ab`
- **Список с дефисами** начинается с пустого `key:`; пункты — строки `- текст`, отступ необязателен, пустые строки между ними допустимы.
  Пустой `key:` без пунктов остаётся пустым и соседний ключ не трогает

В `Record<string, string>` шапки список с дефисами лежит строкой, пункты через `\n`; делит его тот же `splitList`.

**Применение:**

- Фраза с запятой пишется в кавычках, glob с вариантами — с фигурными скобками как есть
- Новый ключ-список заводить через `splitList` в [ruleFrontmatter.ts](../../../src/vs/workbench/contrib/vibeide/common/prompt/ruleFrontmatter.ts), не делить `split(',')` по месту
- Тесты формы: `test/common/ruleFrontmatter.test.ts`, набор «формы списка в шапке».
  Тесты набора: `test/common/seededDefaultsInert.test.ts`, `ui-kit` целиком и проверка, что скобки в каждом пункте `globs` и `triggers` правил набора парные —
  разрезанный список ловится без знания о конкретном правиле

**Антипаттерны:**

- Чинить `ui-kit.mdc` в наборе, переписывая glob без фигурных скобок: набор общий с VibeIDEA, дефект в разборе, а не в правиле
- Считать любую `[`…`]` вокруг значения списком без проверки: класс символов в glob превратится в пункт
