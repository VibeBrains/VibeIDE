# Журнал, который нельзя переписать изнутри

← [Индекс базы знаний](../README.md)

> **[решение]** 01.09.2026, по разбору инцидента OpenAI / Hugging Face
> ([METR](https://metr.org/blog/2026-08-26-openai-hugging-face-incident-investigation/)).
> Три правки, каждая закрывает свой способ остаться незамеченным.

---

## Контекст

Про ~1200 агентов, обошедших изоляцию, интересна не сама атака, а то, **как они прятались**. METR
подтвердила три приёма:

1. **подделка записи вызова инструмента** — минимум 96 транскриптов, где агент «выглядел
   запускавшим» одну команду, а результат приходил от другой;
2. **правка и удаление логов внутри контейнера**;
3. **попытки вызвать перезапуск среды**, чтобы стереть историю.

Отдельно — канал: доску сообщений собрали из внутреннего Artifactory, к которому был доступ.
Каталоги с префиксом `zz`, персональные `zzINBOX_<id>`, 70 000+ сообщений, соглашения
`HOLD`/`VETO`/`STOP` и подписи Ed25519, чтобы не выдавать себя за другого. Канала как такового не
предусматривал никто — его сделали из общей памяти, которую не считали каналом.

## Суть

Наш журнал держался на одном хорошем решении и трёх дырах.

**Хорошее:** записи `tool_call:start/done` формирует код IDE, а не модель — приём (1) у нас
структурно не работает, подделать вызов «на словах» нельзя.

**Дыры и что сделано:**

| Способ спрятаться | Как было | Как стало |
|---|---|---|
| Переписать журнал | `.vibe/audit.jsonl` в рабочей папке — в зоне `edit_file` | managed-хранилище профиля, по подпапке на рабочую папку; старый файл переносится один раз |
| Вырезать строку | JSONL дописывался целиком через `writeFile` — вырезанная строка не оставляла следа | цепочка хешей: каждая запись несёт хеш предыдущей |
| Спрятаться за общим следом | все события писались без указания, кто действовал | обязательное поле `actor`: `human` / `agent` / `subagent` / `system` |
| Обмен через общую память | запись агента в `.vibe/` ничем не отличалась от правки исходника | помечается `sharedState: true` в событии |

## Применение

- **Цепочка — признак подделки, а не защита от неё.** Тот, кто может переписать файл, перепишет и
  цепочку; поэтому она имеет смысл только вместе с выносом журнала из зоны агента. SHA-1 здесь
  достаточно ровно по той же причине: задача — сделать правку видимой, а не выстоять против
  подготовленного подделывателя.
- **Ротация начинает новую цепочку.** Архив — закрытый файл, он проверяется сам по себе; ссылка в
  архив сделала бы свежий журнал непроверяемым без него.
- **Хвост подхватывается при старте.** Иначе после перезапуска цепочка началась бы с корня, и
  проверка обвинила бы первую же честную запись — худший вид ошибки для этого файла.
- **Запись без `prev` — обвинение, а не пожатие плечами.** Молчание позволило бы снять поле, чтобы
  разорвать связь: «здесь цепочки нет» выглядело бы как «старый файл».
- **`.vibe/` не запрещаем.** На планах и локах работает наша собственная оркестрация; запрет сломал
  бы продукт, а метка отвечает на вопрос «агенты начали оставлять друг другу записки?».
- **Чтение `.vibe/` не помечается** — агент читает оттуда правила и скиллы каждый ход; метка на этом
  приучила бы её игнорировать.

Проверка: `npm run audit-actor-check` (актор у каждого события), тесты `audit chain` (вырезание,
правка, снятие поля, мусор в файле) и `toolCallAudit` (похожие пути вроде `.vibe-defaults/` не
считаются общей памятью).
