# Сгенерированные файлы в git отстают от источников молча

← [Индекс базы знаний](../README.md)

> **[грабли+гейт]** Найдено 01.09.2026 при живом смоуке HTTP API: полная компиляция перегенерировала
> `vibeDocsBundle.generated.ts`, и в диффе оказался мануал `manuals/choosingModel.md`, написанный
> днём раньше. Файл в репозитории не совпадал с документацией, из которой он собран.

---

## Контекст

Три модуля собираются из источников и при этом **лежат в git**:

| Файл | Источник | Генератор |
|---|---|---|
| `vibeDocsBundle.generated.ts` | `docs/functional.md`, `docs/README.md`, `docs/manuals/**` | `gen-docs-bundle.mjs` |
| `vibeDefaultsManifest.generated.ts` | набор сидов `.vibe-defaults/` | `gen-vibe-defaults.mjs` |
| `vibeSpecsHelp.generated.ts` | `docs/manuals/specsWorkflow.md` | `gen-specs-help.mjs` |

## Суть

**Сборка всегда свежая — отстаёт версия в репозитории.** Это важно не перепутать: `precompile`
вызывает `gen:all` перед каждой компиляцией, поэтому в собранный продукт документация попадает
актуальной, и релиз ничего не теряет. Проблема в другом:

1. **читающий код видит документацию, которой уже нет** — а бандл существует ровно затем, чтобы
   агент отвечал по нему, не выходя в интернет; расхождение бьёт по правилу «спека должна быть
   пригодна к скармливанию модели»;
2. **дифф всплывает у каждого, кто собирает**, и приучает пролистывать `git status` — так и
   пропускают настоящие изменения;
3. **можно закоммитить бандл, собранный от старых доков**, откатив чужую свежую правку: для git
   это обычное изменение файла, конфликта не будет.

Ни один прежний гейт этого не ловил: `docs-graph-check` проверяет **связность** (файл
проиндексирован и достижим из `README.md`) — `choosingModel.md` проходил его, будучи
несогласованным.

## Применение

- `npm run generated-fresh-check` (`scripts/vibe-generated-fresh.ts`) перегенерирует все три и
  сравнивает с рабочим деревом;
- **гейт ничего не правит за вас**: при расхождении файлы возвращаются в исходное состояние, а
  чинить предлагается руками (`npm run gen:all` + коммит). Проверка, молча исправляющая то, что
  проверяет, — это уже не проверка;
- добавили генератор в `gen:all` — добавьте строку в `GENERATED` в скрипте гейта;
- проверен четырьмя пробами: новый мануал, правка источника спеки и «устаревшая версия в
  репозитории» для каждого из трёх файлов.

Родственное: [[compileAndSync]] — `out/` старше исходников красит прогон зелёным. Тот же класс
ошибки, только там устаревает код, а здесь — сгенерированный артефакт.
