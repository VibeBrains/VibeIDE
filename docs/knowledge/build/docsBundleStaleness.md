# Бандл документации отстаёт от `docs/` молча

← [Индекс базы знаний](../README.md)

> **[грабли]** Найдено 01.09.2026 при живом смоуке HTTP API: полная компиляция перегенерировала
> `vibeDocsBundle.generated.ts`, и в диффе оказался мануал `manuals/choosingModel.md`, написанный
> **31.08**. То есть три дня документ существовал в репозитории, но агент внутри продукта его не
> видел.

---

## Контекст

Пользовательская документация доезжает до агента не из файловой системы, а из вкомпилированного
бандла `src/vs/workbench/contrib/vibeide/common/vibeDocsBundle.generated.ts`. Собирает его
`scripts/gen-docs-bundle.mjs` (`npm run gen:docs-bundle`, входит в `gen:all`).

## Суть

**Написать документ и закоммитить его недостаточно — пока бандл не перегенерирован, продукта эта
документация не касается.** Ни один гейт этого не ловит:

- `npm run docs-graph-check` проверяет **связность** — что файл проиндексирован и достижим из
  `README.md`. Файл `choosingModel.md` этот гейт проходил с 31.08, будучи невидимым для агента;
- у самого генератора нет режима `--check`, поэтому в проверках он не участвует;
- расхождение всплывает только тогда, когда кто-то запустит полную компиляцию и **заметит** чужой
  файл в `git status`. Здесь так и вышло — побочно, не по замыслу.

Опаснее всего это для правила «фича с форматом обязана иметь спеку»: спека пишется ровно затем,
чтобы модель собрала конфиг, **не выходя в интернет и не читая исходники**. Спека, не попавшая в
бандл, проверку готовности из глобального CLAUDE.md не проходит — агент её просто не найдёт.

## Применение

- Тронул что-либо в `docs/` из того, что попадает в бандл (спеки, мануалы, `functional.md`) —
  прогнать `npm run gen:docs-bundle` и закоммитить сгенерированный файл **в той же задаче**;
- увидел `vibeDocsBundle.generated.ts` в `git status` после компиляции — это не мусор сборки, а
  недовезённая документация: смотреть, какой `"file"` добавился, и коммитить;
- проверка фактом: `git diff --stat` по бандлу пуст сразу после `npm run gen:docs-bundle`.

Гейт свежести (тот же генератор с `--check`, падающий на расхождении) напрашивается, но пока не
написан — пункт заведён в [roadmap](../../roadmap.md).

Родственное: [[compileAndSync]] — про то, что `out/` старше исходников красит прогон зелёным. Тот
же класс ошибки, только там устаревает код, а здесь документация.
