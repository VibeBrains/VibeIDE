## [правило] Релиз под macOS собирал голый образ, а не стоковый (2026-09-13)

**Контекст:** VibeIDEA заметила в `build/darwin/` стоковые фоны VS Code с надписью `#HAPPY_CODING!`
и передала, что у VibeIDE окно установки чужое.

**Что оказалось на деле:** эти фоны в релиз не попадали вовсе. `create-dmg.ts` — путь апстрима, ему
нужны Python ≥3.10 и `dmgbuild`, и наш `release-macos.sh` им не пользуется. Релиз собирал образ голым
`hdiutil create -srcfolder`: окно открывалось списком файлов, без фона, без стрелки и без строки про
первый запуск неподписанной сборки. Для неподписанной сборки последнее важнее всего: без него macOS
пишет «повреждено», и приложение удаляют.

**Как сделано:**
- `scripts/build-dmg-macos.sh <app> <dmg>` — образ на запись, раскладка через Finder, сжатие. Только
  системные утилиты. Его зовёт `release-macos.sh`, и его же гоняет стенд на заглушке приложения:
  одна механика для стенда и релиза.
- Фон — `build/darwin/dmg-background.svg`, рендер в двухстраничный `dmg-background.tiff` (1x и 2x).
  Вариант «Пульс» из знака VibeIDE: шина ЭКГ с `{ }` служит стрелкой, словесный знак
  «VibeBrains IDEs», как у VibeIDEA.
- Координаты окна и иконок — константами в скрипте рядом со ссылкой на SVG: это две половины одной
  раскладки.
- **Гейт в самом скрипте:** сжатый образ монтируется, фон сверяется с нашим по sha256, и отсутствие
  `.DS_Store` роняет сборку — иначе образ у получателя откроется списком без единой ошибки.
- `create-dmg.ts` и стоковые фоны апстрима не тронуты: путь нами не используется.

**Грабли замера:**
- Первый замер `checkCentering.py` дал разные ответы на двух одинаковых плашках: −0,5 и +4. Окно
  замера начиналось слишком высоко и захватывало низ светлой папки Applications со значком ярлыка —
  светлое считалось подложкой. Со строки ниже иконки обе плашки согласились. **Разный ответ на
  одинаковых плашках — ошибка замера, а не раскладки.**
- Итог: подпись на 16 точек ниже низа иконки, по центру подложки ±0,5.

**Проверено:** стенд на пустом `.app` с настоящей иконкой — сборка, монтирование сжатого образа,
снимок окна, замер обеих подписей. Полная релизная сборка с этим скриптом ещё не прогонялась.
