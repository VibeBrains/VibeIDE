# Общий файл ролей `.vibe/roles.json`

← [Индекс базы знаний](../README.md)

## [правило] Контракт — файлом набора, константа только запасная (2026-09-13)

**Контекст:** тестовые пути, куда пишет роль `qa`, жили константой в VibeIDE и константой в VibeIDEA,
и держались на договорённости «меняем в обоих или ни в одном». Ровно так уже разошёлся общий набор
(`pricing` → `cost*`). VibeIDEA завела `roles.json` в наборе, мы читаем его.

**Суть:**
- **Ошибка не расширяет границу.** Нет файла, битый файл, нет записи `qa`, не список или пустая
  строка внутри — встроенный список. `writePaths: []` — запрет записи, а не «без ограничений».
- **Пайплайн читает файл один раз на прогон**, делегирование от оркестратора — при запуске роли.
  Правка посреди прогона не сдвигает границу между шагами.
- **Грабля реализации:** снимок пайплайна нельзя передать через `writeScope` шага. Пустой список путей
  там значит «шаг путей не назвал», и сервис субагентов прочитал бы файл заново посреди прогона —
  а запрет `[]` превратился бы во встроенный список. Поэтому список роли едет отдельным полем
  `qaWritePaths` задания.
- **Тест сверяет засеянный файл со встроенной константой** — как у VibeIDEA. Изменение одного без
  другого падает в тесте, а не у пользователя.
