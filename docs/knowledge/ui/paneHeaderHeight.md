# Высота заголовка панели — только через раскладку VS Code

## [баг] Последняя строка списка в боковой панели не доскролливалась (10.11.2026)

Раскладка VS Code отдаёт телу панели «высота минус заголовок» и берёт высоту заголовка из `setGlobalPaneHeaderSize` (по умолчанию 22)
С первого импорта наш `vibeide.css` поднимал заголовок до 32 px через `min-height` и отступы, а телу добавлял нижний отступ
Раскладка этого не знала: содержимое сдвигалось вниз, и низ списка (на графе Git — последний коммит) уходил за край

Теперь высота задаётся двумя согласованными значениями:
`VIBE_PANE_HEADER_SIZE = 32` в `contrib/styleOverrides/browser/styleOverrides.contribution.ts` — раскладка
`--pane-header-size: 32px` в `vibeide.css` на `.monaco-workbench:not(.style-override) .monaco-pane-view` — вид
Экспериментальная тема VS Code (`workbench.experimental.modernUI`, класс `.style-override`) ставит свои 28 px, мы её не перебиваем

Правило: размер, который учитывает раскладка (высота заголовка, строки списка, полосы прокрутки), меняется только через её API, а не CSS-ом поверх
