# Граф документов: canvas, силовая раскладка, паритет с гейтом

← [Knowledge Index](../README.md)

Визуальный граф связей `docs/**` — вкладка редактора (полный граф) + секция «Связи документа» в панели (локальный граф). Панель-дерево, поверх которой он живёт, — [[vibeDocsPane]]. Гейт, с которым он обязан совпадать, — `scripts/vibe-docs-graph.mjs`.

---

## [архитектура] Две реализации одного парсера — осознанный дубль (2026-07-15)

**Контекст:** гейт `docs-graph-check` уже парсил связи. Соблазн: переиспользовать его код из workbench.

**Суть:** **нельзя.** В roadmap:76 зафиксировано, что скрипт **бездепный** — CI гоняет его без `npm ci`, поэтому импортировать TypeScript из `src/` он не может физически. Обратное (workbench импортирует `.mjs` из `scripts/`) ломает сборку и слои.

Решение: два парсера, паритет держится **тестом поведения**, а не обещанием.

| | путь |
|---|---|
| модель (workbench) | `common/vibeDocsGraph.ts` — чистая, на `base/common/path` |
| гейт (CI) | `scripts/vibe-docs-graph.mjs` — чистые хелперы вынесены в `export`, исполнение в `main()` под CLI-guard |
| тест паритета | `test/node/vibeDocsGraphParity.test.ts` — **новый слой `test/node/` для vibeide** (прецедент `platform/agentHost/test/node`); динамически импортирует `.mjs` и сверяет разбор на корпусе ловушек |

`test/node` виден раннеру сам (`npm run test-node` = mocha по `**/test/**/*.test.js`), правки конфигов не нужны. Корень репо тест находит по `import.meta.url`, отрезая `/out/` или `/src/`.

**Применение:** меняешь правило разбора ссылок — меняй в ОБОИХ и гоняй тест паритета. Дубль легален только пока тест жив.

## [баг] Гейт не видел `[[wikilinks]]` — минус 39 рёбер (2026-07-15)

**Контекст:** скрипт с рождения парсил только `[текст](путь.md)`. Но шаблон записи предлагает **оба** формата, и база реально использует wikilinks.

**Суть:** замер до правки — 384 ребра, после — **423**. Гейт не видел ~10% связей базы знаний и мог назвать «недостижимым» документ, на который ссылались.

Инвентаризация перед правкой (обязательный шаг, иначе CI падает вслепую):
- 43 wikilink-ссылки разрешаются, **0 неоднозначных**, **1 битая** — `[[T. Modern features survey]]` в `roadmap.md`.
- Битая оказалась **не ссылкой на документ**, а отсылкой к секции того же файла в obsidian-стиле. Починка — обычный якорь `[…](#t-modern-features-survey-2026-05-21)`, а не создание файла.

Мусор (`[['a','А'],['b','Б']]` из примеров кода, `[[REDACTED:AWS Secret Key]]` из лога, сам `[[wikilink]]` из текста конвенций) **отсекается уже существующей вырезалкой кода** — все они живут в бэктиках. Дополнительная защита: регулярка требует закрывающие `]]`, а `[['a','А'],` их не даёт.

**Применение:** прежде чем включать новое правило в гейт — **измерить** его эффект на реальном корпусе скриптом, а не гадать. Стоимость оказалась в одну правку ссылки.

## [правило] Резолв wikilink: имя без пути (2026-07-15)

**Суть:** `[[entry]]` не несёт пути. Порядок: точный docs-relative путь → **уникальный** basename. Неоднозначный basename резолвится в **ничто и репортится битым** — молча выбрать один из двух одноимённых доков значит нарисовать ребро, которого нет. Поддержаны `[[a|алиас]]` и `[[a#якорь]]`.

**Применение:** появятся два одноимённых дока в разных доменах — ссылки на них по короткому имени станут битыми. Это не баг, а сигнал: ссылаться полным путём.

## [квирк] Активный док не выводится из активного редактора (2026-07-15)

**Контекст:** локальный граф должен следовать за открытым доком. Наивно — `editorService.activeEditor.resource`.

**Суть:** **не работает и молча даёт пустой граф.** Панель «Документы» открывает markdown в **превью**, а у webview `resource` — синтетический хэндл (`webview-panel://…`), не файл. Основной сценарий панели (клик → превью) не даёт узнать, какой док открыт.

Это **повтор уже записанного капкана**: в roadmap:648 чип «Файл» в чате печатал `webview-markdown.preview-<guid>` ровно по той же причине.

Решение: активный док **сообщается**, а не угадывается — `IVibeDocsGraphService.setActiveDoc(uri)` + `onDidChangeActiveDoc`. Зовут: панель при открытии дока (превью и исходник), сам граф-view при смене редактора (для доков, открытых из Проводника/Quick Open — там ресурс настоящий). Не-док редакторы **не сбрасывают** последний известный док, иначе граф гаснет при переходе в любой другой таб.

**Применение:** любая фича, которой нужен «текущий markdown», обязана учитывать превью-webview. `activeEditor.resource` для этого негоден.

## [квирк] Canvas + силовая раскладка: три грабли (2026-07-15)

**Суть:**

1. **«Вписать в экран» нельзя звать сразу.** Симуляция на старте ещё расходится: подгонка на t=0 кадрирует граф, который продолжает расти, и к моменту остывания он **обрезан**. Поймано глазами на скриншоте. Виewport двигаем **на остывании** (`_fitOnSettle` / `_centerOnSettle`), не раньше.
2. **rAF нельзя крутить вечно** — это баг «вентилятор ноутбука». Цикл живёт, пока энергия выше `LAYOUT_SETTLED_ENERGY`, дальше стоп и перерисовка только по требованию.
3. **Клик ≠ конец драга.** Узел таскают мышью; без порога (`DRAG_THRESHOLD_PX`) каждый драг открывал бы док.

Прочее по месту: раскладка **детерминированная** (golden-angle спираль, без `Math.random`) — иначе картинка разная на каждый вход и не тестируется; позиции переносятся между перестройками графа, чтобы правка одного дока не перетасовывала всё; DPR через `PixelRatio` (эталон `notebookOverviewRuler.ts`), цвета — `Themable.getColor()` + перерисовка на `updateStyles()`, потому что CSS канву не перекрашивает.

**Применение:** отталкивание O(n²) сознательно — 214 узлов это ~20k пар за тик, влезает в кадр. Barnes-Hut городить только если корпус вырастет на порядок.

## [правило] Цвета — из палитры темы, не свои (2026-07-15)

**Суть:** домены (`ui/`, `architecture/`, …) — имена папок, известные только в рантайме, поэтому токен на домен не зарегистрировать. Берём готовую палитру `charts.*` (`colors/chartsColors.ts`: blue/green/purple/orange/yellow/red — уже темизирована под light/dark/HC) + стабильный хэш имени домена. Свои токены заведены только на то, чего в палитре нет по смыслу: `vibeide.docsGraph.unreachable`, `.deadLink`, `.edge`.

**Применение:** хэш обязан быть стабильным (не индекс регистрации) — иначе домен меняет цвет между запусками.

## [квирк] Смоук CDP: чем врут проверки (2026-07-15)

Три ложных «бага», стоившие времени, — все в **проверке**, не в коде:

- **CSS-переменные темы живут не на `documentElement`.** `getComputedStyle(document.documentElement)` вернул «нет» даже для `--vscode-editor-background`. Читать с `.monaco-workbench`.
- **В палитре команд первый символ `>`.** Затираешь value целиком — палитра превращается в поиск по файлам и честно отвечает «не найдено». Писать `">Команда"`.
- **Заголовки панелей выглядят заглавными из-за CSS `text-transform`**, а в `textContent` — исходный регистр («Связи документа», не «СВЯЗИ ДОКУМЕНТА»).

Ещё: дерево панели **виртуализировано** — в DOM только видимые строки, `roadmap` внизу списка просто отсутствовал. И `~/.Trash` на macOS закрыт TCC — проверить «ушло ли в корзину» из смоука нельзя.

**Применение:** прежде чем поверить, что фича сломана, проверить сам зонд на заведомо рабочем объекте.
