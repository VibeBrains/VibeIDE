# Первый запуск: предупреждения Windows и macOS

← [Документация](../README.md)

VibeIDE распространяется **без сертификата издателя**, поэтому при первом запуске система показывает предупреждение. Это нормально и ожидаемо: ОС сообщает, что не может подтвердить издателя, а не то, что нашла что-то плохое. Ниже — что именно нажать.

Почему так: сертификат Microsoft Authenticode и Apple Developer ID стоят денег и привязаны к юридическому лицу; пока их нет, установщик остаётся неподписанным. Исходный код открыт, сборку можно повторить самому — см. [buildFromSource](../knowledge/build/buildFromSource.md).

---

## Windows

При запуске `VibeIDESetup.exe` появляется синее окно **«Система Windows защитила ваш компьютер»** (SmartScreen).

1. Нажмите **«Подробнее»** — по умолчанию окно показывает только кнопку «Не выполнять».
2. Нажмите появившуюся кнопку **«Выполнить в любом случае»**.

Установка пойдёт как обычно. Предупреждение появляется один раз для конкретного файла: следующая версия — снова, потому что подписи у неё по-прежнему нет.

Альтернатива без предупреждения — `winget`, он берёт пакет из каталога Microsoft:

```powershell
winget install VibeBrains.VibeIDE
```

## macOS

Здесь порядок действий **зависит от версии системы**, и это главная причина, по которой старые советы из интернета не работают.

### macOS 15 (Sequoia) и новее — включая 26 (Tahoe)

Начиная с Sequoia Apple **убрала** обход через контекстное меню: Control-клик → «Открыть» больше не помогает ([анонс Apple для разработчиков](https://developer.apple.com/news/?id=saqachfa)). Если вы видите окно **«Файл "VibeIDE.app" не был открыт»** с единственной кнопкой «Готово» — вы попали именно в этот случай.

1. Перетащите `VibeIDE.app` из образа `.dmg` в **Программы** и **закройте образ**.
2. Запустите приложение обычным двойным кликом. Появится то самое окно — нажмите **«Готово»**. Этот шаг обязателен: без попытки запуска система не покажет нужную кнопку в настройках.
3. Откройте **Системные настройки → Конфиденциальность и безопасность**.
4. Прокрутите до раздела **«Безопасность»**. Там будет строка о том, что запуск «VibeIDE.app» заблокирован, и кнопка **«Открыть всё равно»** (в разных версиях подписана как «Всё равно открыть» / «Open Anyway»).
5. Нажмите её и подтвердите Touch ID или паролем администратора.
6. Запустите VibeIDE ещё раз — в диалоге выберите **«Открыть»**. Дальше приложение открывается обычным способом.

Кнопка в настройках появляется только после попытки запуска и относится к конкретному приложению — то есть шаг 2 пропускать нельзя.

### macOS 14 (Sonoma) и старше

Здесь работает короткий путь:

1. Перетащите `VibeIDE.app` в **Программы**.
2. **Control-клик** (или правый клик) по приложению → **«Открыть»**.
3. В диалоге нажмите **«Открыть»** ещё раз.

### Через терминал — любая версия

Предупреждение вызывает метка «скачано из интернета» (атрибут `com.apple.quarantine`). Её можно снять одной командой:

```bash
xattr -dr com.apple.quarantine /Applications/VibeIDE.app
```

После этого приложение запускается без диалогов. Команда рекурсивная (`-r`), потому что метка ставится и на вложенные файлы бандла.

Проверить, что метка снята:

```bash
xattr -p com.apple.quarantine /Applications/VibeIDE.app
```

Ответ `No such xattr` означает, что метки больше нет.

## Чего ожидать не нужно

- **`spctl -a -t execute` всё равно скажет `rejected`.** Это оценка политики Gatekeeper, а не приговор запуску: подпись у нас ad-hoc, и такой вердикт для неё нормален даже после снятия карантина. Ориентируйтесь на то, запускается ли приложение, а не на вывод `spctl`.
- **Отключать Gatekeeper целиком (`spctl --master-disable`) не нужно.** Это снимает защиту со всей системы ради одного приложения — несоразмерная плата; все способы выше работают точечно.

## Как убедиться, что файл не подменили

У каждого релиза на [странице релизов](https://github.com/VibeBrains/VibeIDE/releases) GitHub показывает свои артефакты. Сверить скачанное можно так:

```bash
shasum -a 256 ~/Downloads/VibeIDE-1.9.1-darwin-arm64.dmg
```

```powershell
Get-FileHash .\VibeIDESetup.exe -Algorithm SHA256
```

Значение должно совпадать с суммой из релиза. Если релиз сумму не приводит — сравните с тем, что даёт самостоятельная сборка из исходников.
